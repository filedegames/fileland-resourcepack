# Pack de recursos da FiléLand

Versão de rede para Java e Bedrock com Geyser. Compatível com Minecraft Java 26.3 e Bedrock 1.26+.

## Downloads

- [Java (ZIP)](https://github.com/filedegames/fileland-resourcepack/raw/refs/heads/main/fileland-java.zip)
- [Bedrock (MCPack)](https://github.com/filedegames/fileland-resourcepack/raw/refs/heads/main/fileItens-bedrock-1.1.8%2Bmc26.3-fileland-network-pack.mcpack)

No Java, o servidor envia o pack ao entrar. No Bedrock via Geyser, instale o `.mcpack` no dispositivo; para distribuição automática, o administrador deve converter/instalar o pack em `plugins/Geyser-Velocity/packs` e ativar `force-resource-packs` no proxy. Mantenha o mesmo pack no proxy e nos servidores para evitar prompts ao trocar de servidor.

O ícone FiléLand está incluído nos dois formatos. Atualizações serão publicadas junto com os hashes e a versão do plugin.
